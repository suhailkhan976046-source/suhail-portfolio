This personal portfolio introduces me as a B.Tech Computer Science and Engineering student at ABES Institute of Technology, expected to graduate in 2027, and an aspiring Java Full Stack Developer. It includes a responsive navigation bar, a hero introduction, an About section with education details, a technology skills grid, two academic/personal project summaries, and contact links. The site is built with semantic HTML5 and a separate CSS3 stylesheet using CSS Grid, Flexbox, hover/focus states, and responsive media queries. It uses no JavaScript, frameworks, backend services, or database, in line with the internship requirements.
